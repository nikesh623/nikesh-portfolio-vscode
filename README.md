# Nikesh Kumar Sah — Portfolio Website

A static portfolio website for Nikesh Kumar Sah, set up for local development and preview in Visual Studio Code.

## Preview in VS Code

1. Open this folder in Visual Studio Code.
2. Install the recommended **Live Server** extension if needed.
3. Open `index.html` and select **Go Live** in the status bar. The site opens at `http://127.0.0.1:5500`.

No Node.js packages are required. You can also run `python3 -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Project files

- `index.html` — portfolio content and page structure
- `styles.css` — responsive layout, colors, and themes
- `script.js` — navigation, theme toggle, and contact form behavior
- `assets/amber-vr-portrait.png` — hero artwork
- `assets/NikeshKumarSahCV.pdf` — downloadable CV
- `public/nks-mark.svg` — site favicon and brand mark
- `.vscode/` — Live Server recommendation and workspace settings

The personal portrait is not included. The site loads its fonts from Google Fonts, so an internet connection is needed for those fonts; the rest of the page runs locally.
